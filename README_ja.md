# Agora

[English](README.md) | [中文](README_zh.md) | **日本語**

**Agora は、複数のコーディング Agent（Claude Code・Codex・Kiro）で複数のプロジェクトを同時に進める人のための、ローカルファーストな開発ワークベンチです。**

朝に開けば、各プロジェクトが昨日どこで止まったか、何があなたを待っているか、次に何をするかが一目で分かります。タスクを選べば、同じ Agent との同じ会話に、正しいマシン上で戻れます。作業が終われば、状態は本来あるべき場所——Agora だけが読めるデータベースではなく、プロジェクト自身のリポジトリ——に書き戻されます。

```text
概要（全プロジェクト、あなたを待っているもの）
   -> 作業ページ（1 タスク = Agent との 1 つの継続した会話）
   -> レビューゲート（コミット前に別の Agent がレビュー）
   -> 状態の書き戻し：目標、変更記録（CR）、設計判断（ADR）、進捗
```

現在のバージョン：**1.10.1**。UI は English / 中文 / 日本語 に対応。

## 機能

- **概要がトップページ。** 登録したワークスペースのディレクトリから取り込んだプロジェクトごとに 1 枚のカード。進行中の作業、あなた待ちの項目、コミットレビューゲートの記録、どのワークスペース由来かを表示します。プロジェクトは一時停止・アーカイブ・復元が可能で、タスクは「未着手 / 進行中」に分かれ、ドラッグで並べ替えられます。
- **1 タスク = 1 つの継続した会話。** 作業ページは履歴を再送するのではなく、Agent 自身のセッション（Claude Code / Codex / Kiro）を再開し、出力をリアルタイムでストリーミングします。実行中のターンがどれだけ無出力のままかも正直に表示します。Agora の外で続けた会話も拾い直し、再起動時には実行中だった作業を復旧します。
- **実装担当と、別のレビュー担当。** 各プロジェクトは実装 Agent と、それとは*異なる*レビュー Agent を固定します——自分で自分をレビューしても意味がないからです。レビューゲートが実際に変更を読むまで、何もコミットされません。
- **既存の作業をその場で読む。** ワークスペースに既にあるタスク記録（`tasks/<name>/{task.yaml, RESUME.md, WORKFLOW.md, adr/}`）をライブで読み、そのまま表示します——目標、変更記録、設計判断、進捗スナップショット。Agora のデータベースにはコピーしないので、同期の問題も起きません。
- **SSH 経由のリモート環境。** ホストを登録し（`~/.ssh/config` から選択も可）、接続をテストし、ホスト鍵を確認してから信頼し、その上でタスクを実行したりターミナルを開いたりできます。認証情報は手元の SSH 鍵、または OS のキーリングに保存したパスワードです。
- **内蔵ターミナル。** Agora 内の対話型ターミナル。ローカルでも登録済みのリモートホストでも、タスクを開いた状態で起動します。
- **スキルライブラリ。** Agent Skills 標準に沿った 1 つのスキルライブラリを、プロジェクト単位で Claude・Codex・Kiro にインストールします。公開されているスキルリポジトリを取得・閲覧・取り込みでき、インストール前に中身を読めます。
- **使用量がすぐ分かる。** すべてのページの下部に各 Agent の残り枠を表示——Claude は自身の `/usage`（Team プラン含む）から、Kiro はクレジットを表示します。
- **デスクトップアプリ。** ウィンドウ・トレイアイコン・ワンクリック更新を備えたインストール可能な Windows アプリ。内部では同じ起動スクリプトを使います。
- **安定版と開発版を分離。** 安定版は必ずリリースタグそのもの。更新前にデータベースをバックアップし、どこかで失敗すればロールバックします。開発用チェックアウトは専用のポート・データベース・キーリング名前空間で動き、安定版のデータには触れません。

### すべてを貫く 1 つのルール

**Agora は、読み取れていないことを断言しません。**「読めなかった」「不明」「なし」は 3 つの異なる答えで、決して一緒にしません。「不明」と言う未完成の画面は毎日安心して使えますが、「読めなかった」を「なし」と言う画面は、あなたに誤った判断をさせます。

## 動作環境

- Windows 10/11、PowerShell 5.1 以上（起動スクリプトとデスクトップアプリは Windows 専用。バックエンド自体は通常の Python です）
- Python 3.10+ と [uv](https://docs.astral.sh/uv/)
- Node.js 20+ と `corepack`（pnpm）
- Git
- インストール済みでログイン済みの Agent CLI を 1 つ以上：`claude`、`codex`、`kiro-cli`。Agent は明示的に固定されたアダプタです——見つからない、またはログアウトしている場合、その作業はブロックされ、黙って別のものに置き換えられることはありません。

## クイックスタート

```powershell
git clone https://github.com/wilbur-labs/Agora.git
cd Agora

cd backend
uv sync --locked --extra dev
cd ..\frontend
corepack pnpm install --frozen-lockfile
corepack pnpm build
cd ..

.\agora.ps1 up          # バックエンドを起動し、/health を待って Agora を開く
```

ビルド済みのフロントエンドはバックエンドが配信するので、普段は `http://127.0.0.1:8000` の 1 プロセスだけです。その他のコマンド：

```powershell
.\agora.ps1 down        # 停止（ポート上の Agora 以外のプロセスは止めない）
.\agora.ps1 status      # 実行中か、pid、フロントエンドのビルドが古くないか
.\agora.ps1 logs        # バックエンドログの末尾 40 行
.\agora.ps1 up -Build   # フロントエンドを再ビルドしてから起動
.\agora.ps1 shortcut    # デスクトップに「Agora」ショートカットを作成
.\agora.ps1 up -Dev     # このチェックアウトを開発版としてポート 8001 で起動
```

### 自己更新できる安定版

リリースタグを専用のディレクトリにチェックアウトし、普段はそれを使います：

```powershell
git clone https://github.com/wilbur-labs/Agora.git Agora-stable
cd Agora-stable
git checkout v1.10.1
# 上と同じ手順で依存関係をインストールしてビルドし、その後：
.\agora.ps1 up
.\agora.ps1 upgrade -To v1.11.0   # 後日の更新：バックアップ、チェックアウト、ビルド、起動、検証——失敗時はロールバック
.\agora.ps1 rollback -Yes          # 直前の更新より前のバージョンに戻す
```

### デスクトップアプリ

```powershell
cd desktop
npm install
npm run build           # desktop\dist に NSIS インストーラを生成
```

アプリは `agora.ps1` を通じて Agora を起動・更新するため、安全チェックはすべて 1 か所にまとまっています。

## はじめの一歩

1. **設定 → 作業データの取得元**：タスク記録が既にあるディレクトリを登録します。Agora は保存前に各ディレクトリを調べ、何が読めたか——読めなかったものも含めて——を表示します。
2. それらのワークスペースから**プロジェクトを取り込む**か、新規作成します。実装 Agent とレビュー Agent を選びます。
3. **概要**：タスクを選び、作業ページで続けます。
4. 任意：**環境**でリモートホストを追加、**スキル**でプロジェクトにスキルをインストール。

## アーキテクチャ

| 部分 | パス | 説明 |
|---|---|---|
| バックエンド | `backend/agora/` | FastAPI + SQLite。Claude Code / Codex / Kiro アダプタ、セッションとライブ転写、プロジェクトレジストリ、ワークスペース読み取り、SSH 環境、ターミナル、スキル |
| フロントエンド | `frontend/` | Next.js。静的ファイルにビルドし、バックエンドが配信 |
| デスクトップ | `desktop/` | `agora.ps1` を包む Electron シェル |
| 起動スクリプト | `agora.ps1` | 起動 / 停止 / 状態 / 更新 / ロールバック |
| 設計判断 | `.agora/decisions/` | アーキテクチャ決定記録（ADR） |

Agora 1.0 の形式的なコントロールプレーン（要件、ワークフロー、ステージゲート）はコードベースに残り、テストもされていますが、凍結済みでメインナビゲーションからは外れています。

## 開発

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest tests -m "not integration"
cd ..\frontend
corepack pnpm test:control-plane
corepack pnpm exec tsc --noEmit
cd ..
git diff --check
```

AI プロバイダを一切呼ばず、データベースにも触れずに、制御経路全体を通しで確認するには：

```powershell
.\backend\.venv\Scripts\python.exe scripts\run_task_acceptance.py
```
